
Este repositorio contiene la documentación oficial de Ahorra Ya, una plataforma web diseñada para ayudar a los usuarios a descubrir, compartir y publicar ofertas de sus negocios favoritos.

Aquí encontrarás información detallada sobre la arquitectura del sistema, funcionalidades, guías de uso, y especificaciones técnicas del proyecto.
La documentación está organizada para facilitar su consulta por parte de desarrolladores, colaboradores y usuarios interesados en comprender el funcionamiento y propósito de Ahorra Ya.
